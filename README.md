## 🛠️ Included Systems Modules

| Module | File | Architecture Description |
| :--- | :--- | :--- |
| **Custom Memory Allocator** | `my_malloc.c` | Heap memory allocator utilizing Unix `sbrk`, free-list blocks, and 8-byte alignment. |
| **Minimalist Unix Shell** | `micro_shell.c` | POSIX-compliant shell with process forking (`fork`/`execvp`), signal handling, and built-ins. |
| **I/O Throughput Benchmarker** | `io_bench.c` | High-precision timing suite comparing buffered standard C I/O against raw POSIX system calls. |
| **Stack Bytecode Virtual Machine** | `vm.c` | Custom stack-based instruction execution engine written in bare-metal C. |
